# 📓 나의 옵시디언 볼트 (Obsidian × Claude)

애플 메모(Apple/삼성 메모)를 옵시디언으로 옮기고, **Mac · 아이폰 · 아이패드**에서 함께 쓰며, **Claude와 연동**하기 위한 저장소입니다.

이 저장소 자체가 하나의 **옵시디언 볼트(Vault)** 뼈대예요. 아래 순서대로만 따라오면 됩니다.

---

## 🚀 빠른 시작 (5단계)

| 단계 | 내용 | 가이드 |
|------|------|--------|
| 1️⃣ | 옵시디언 설치 (Mac·아이폰·아이패드) | [docs/01-옵시디언-설치.md](docs/01-옵시디언-설치.md) |
| 2️⃣ | 애플/삼성 메모 → 옵시디언 가져오기 (⚡ 자동 스크립트 `tools/migrate.sh`) | [docs/02-애플메모-가져오기.md](docs/02-애플메모-가져오기.md) |
| 3️⃣ | 3개 기기 동기화 (iCloud 권장) | [docs/03-기기간-동기화.md](docs/03-기기간-동기화.md) |
| 4️⃣ | Claude 연동 (메모를 AI가 읽고 씀) | [docs/04-Claude-연동.md](docs/04-Claude-연동.md) |
| 5️⃣ | 매일 쓰기 (수집 → 정리 → 활용) | [docs/05-매일-사용법.md](docs/05-매일-사용법.md) |

> 처음이라면 **1 → 2 → 3 → 4** 순서 그대로 진행하세요. 각 문서는 5~10분이면 끝납니다.

---

## 📁 폴더 구조

```
📓 볼트 루트
├── 00-Inbox/       ← 새 메모·생각을 일단 여기에 (수집함)
├── 10-Notes/       ← 정리된 메모 (애플 메모에서 옮겨온 것들)
├── 20-Ideas/       ← 아이디어·기획·영감
├── 30-Projects/    ← 진행 중인 프로젝트별 노트
├── 90-Archive/     ← 끝났거나 보관용
├── Templates/      ← 새 노트 템플릿 (노트/아이디어/데일리)
└── docs/           ← 이 셋업 가이드 문서들
```

**규칙은 딱 하나:** 새로운 건 무조건 `00-Inbox`에 넣고, 나중에 정리할 때 알맞은 폴더로 옮기면 됩니다. (Claude에게 "인박스 정리해줘"라고 시킬 수도 있어요.)

---

## 🤖 Claude로 뭘 할 수 있나요?

연동을 마치면 이런 걸 시킬 수 있습니다:

- "인박스에 쌓인 메모들 주제별로 정리해서 알맞은 폴더로 옮겨줘"
- "지난주에 적은 아이디어들 요약해줘"
- "이 흩어진 메모 3개를 하나의 글로 합쳐줘"
- "관련 있는 노트끼리 `[[링크]]`로 연결해줘"
- "이 아이디어 발전시켜서 실행 계획 만들어줘"
