# 2️⃣ 애플/삼성 메모 → 옵시디언 가져오기

기존 메모를 옵시디언으로 옮기는 방법입니다. **가장 쉬운 순서대로** 정리했어요. Mac에서 진행하는 걸 추천합니다.

---

## ⚡ 가장 빠른 길: 자동 이전 스크립트 (권장)

수작업 없이 **명령어 한 줄**로 애플 메모 전체를 옮길 수 있게 스크립트를 준비해 뒀습니다.

```bash
# 볼트 폴더(터미널)에서
bash tools/migrate.sh
```

- 모든 애플 메모 → `10-Notes/애플메모/` 에 마크다운으로 자동 변환 (폴더·제목·생성일 보존)
- 실행 중 "메모 앱 접근 허용"을 물으면 **허용**
- 삼성 메모/기타 파일은 `bash tools/import-files.sh <폴더>` 사용
- 자세한 설명: **[../tools/README.md](../tools/README.md)**

> 스크립트 없이 손으로 하고 싶다면 아래 방법들을 참고하세요.

---

## 🍎 애플 메모(Apple Notes) — 권장: Importer 플러그인

옵시디언 공식 **Importer** 플러그인이 애플 메모를 직접 읽어옵니다. 가장 깔끔해요.

### 준비
1. **Mac의 "메모" 앱을 한 번 열어** iCloud 메모가 전부 내려받아졌는지 확인 (동기화 완료 상태여야 함)
2. 옵시디언에서 **Settings(설정) → Community plugins → "Turn on community plugins"** 켜기
3. **Browse** → `Importer` 검색 → **Install** → **Enable**

### 가져오기
1. 왼쪽 리본 또는 명령 팔레트(`Cmd+P`)에서 **"Importer: Open import dialog"** 실행
2. **Apple Notes** 선택
3. 저장 위치를 **`10-Notes`** 폴더로 지정
4. **Import** 클릭 → 메모, 폴더, 첨부(이미지 등)까지 마크다운으로 변환됩니다

> ⚠️ macOS가 "메모 앱 접근 허용" 권한을 물어보면 **허용**하세요. 접근이 안 되면 아래 대체 방법(내보내기)을 쓰세요.

---

## 🍎 애플 메모 — 대체 방법: 수동 내보내기

Importer가 안 될 때 (권한 문제 등):

1. Mac 메모 앱에서 옮길 메모 선택 (여러 개는 `Cmd` 클릭으로 다중 선택)
2. **File → Export as PDF** … 는 편집이 안 되니 비추천.
   대신 각 메모에서 본문을 **복사 → 옵시디언 새 노트에 붙여넣기**
3. 양이 많으면: 메모를 한 개씩 열어 **공유 버튼 → 복사** 후 옵시디언에 붙여넣기

> 메모가 아주 많다면 Importer 방식을 꼭 먼저 시도하세요. 수동은 몇십 개 이하일 때만 현실적이에요.

## 📱 삼성 메모(Samsung Notes)

삼성 메모는 옵시디언 직접 임포터가 없어서 **텍스트로 내보낸 뒤 옮깁니다.**

### 방법 1) 삼성 메모 → 텍스트 파일
1. 삼성 메모 앱 → 메모 열기 → **⋮ (더보기) → 파일로 저장 / 내보내기 → TXT 또는 PDF**
2. TXT로 저장되면 그 파일을 옵시디언 볼트의 `10-Notes` 폴더에 넣고 확장자를 `.md`로 변경
3. 여러 개면 하나씩 반복

### 방법 2) 삼성 메모 → 노트북/드라이브 → 옵시디언
1. 삼성 메모를 **Microsoft OneNote로 동기화**하거나 **Google Drive로 내보내기**
2. 거기서 텍스트를 복사해 옵시디언에 붙여넣기

> 💡 삼성 메모의 **손글씨/그림**은 텍스트로 안 바뀝니다. 이미지로 내보낸 뒤 옵시디언 노트에 첨부(`![[이미지.png]]`)하는 방식으로 보관하세요.
