# 3️⃣ 기기 간 동기화 (Mac · 아이폰 · 아이패드)

같은 볼트를 세 기기에서 함께 보려면 동기화가 필요합니다. 애플 기기만 쓰시니 **iCloud가 가장 간단**합니다.

---

## ⭐ 방법 A) iCloud Drive — 애플 3대라면 이게 정답 (무료·추천)

Mac·아이폰·아이패드 모두 애플 기기라, iCloud로 자동 동기화됩니다.

### Mac에서 볼트를 iCloud에 두기
1. 볼트 폴더를 **iCloud Drive 안**으로 이동
   (예: `iCloud Drive/Obsidian/나의볼트/`)
2. 옵시디언 → **Open folder as vault** → 그 폴더 선택

### 아이폰 / 아이패드에서 같은 볼트 열기
1. 옵시디언 앱 실행 → **"Open folder as vault"** 또는 첫 화면에서 iCloud 선택
2. 아이폰은 iOS 옵시디언이 **자체 iCloud 컨테이너**를 쓰기도 합니다. 이 경우:
   - 아이폰 옵시디언에서 **"Create/Store in iCloud"** 옵션으로 볼트 생성
   - Mac에서 `iCloud Drive/Obsidian/` 경로에 그 볼트가 나타나면 성공

> ✅ **장점:** 무료, 자동, 설정 간단, 애플 기기 완벽 지원
> ⚠️ **주의:** 한 기기에서 편집 후 **몇 초~1분** 기다렸다가 다른 기기를 여세요. 동시에 같은 노트를 편집하면 충돌 사본이 생길 수 있어요.

---

## 방법 B) Obsidian Sync — 공식 유료 (가장 안정적)

옵시디언이 직접 제공하는 동기화. 월 몇 달러지만 충돌 관리·버전 기록·암호화가 최고 수준입니다.

1. 옵시디언 → **Settings → Sync** → 계정 로그인 후 구독
2. 각 기기에서 같은 Sync 원격 볼트에 연결

> 💰 돈이 들지만 "동기화 스트레스 0"을 원하면 최선. 손글씨 많고 첨부 많은 볼트에 특히 유리.

---

## 방법 C) iCloud + Git 병행 (이 저장소 활용)

**기기 동기화는 iCloud, 버전 백업/Claude 작업은 이 Git 저장소**로 병행하는 고급 세팅입니다.

- 일상 편집·동기화 → **iCloud** (자동)
- 백업·이력 관리·웹 Claude 작업 → **Git** (`git commit`/`push`)
- Mac에서 가끔 `git add . && git commit -m "메모 백업" && git push` 해두면 안전망이 됩니다

> 아이폰/아이패드에서 Git을 직접 다루긴 번거로워요(플러그인 필요). **모바일은 iCloud만, Mac에서만 Git** — 이 조합이 현실적입니다.

---

## 🧭 결론: 뭘 고르죠?

| 상황 | 추천 |
|------|------|
| 그냥 간단하게, 무료로 | **A) iCloud** |
| 충돌·백업 완벽하게, 돈 OK | **B) Obsidian Sync** |
| 버전 이력 + 웹 Claude도 쓸래 | **C) iCloud + Git** |

대부분은 **A(iCloud)** 로 충분합니다. 나중에 필요하면 B나 C를 얹으면 돼요.
