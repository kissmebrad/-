# 5️⃣ 매일 사용법 — 수집 → 정리 → 활용

세팅이 끝났다면, 이제 습관만 남았습니다. 복잡하게 생각하지 마세요. **"일단 인박스"** 원칙 하나면 됩니다.

---

## 🔁 기본 흐름

```
생각/메모 발생  →  00-Inbox 에 일단 던지기  →  가끔 정리(직접 or Claude)  →  알맞은 폴더로
```

1. **수집(Capture):** 떠오르는 건 무조건 `00-Inbox`에 새 노트로. 형식 신경 X.
   - 아이폰에서도 옵시디언 열고 바로 적기 → iCloud로 Mac에 동기화됨
2. **정리(Organize):** 주 1~2회, Claude에게 인박스 정리 맡기기
3. **활용(Use):** 정리된 메모로 글쓰기·기획·아이디어 발전

---

## 🤖 Claude에게 시키면 좋은 것들 (복붙용 예시)

**정리**
- "00-Inbox 메모들 주제별로 묶어서 10-Notes / 20-Ideas 폴더로 분류해줘. 각 노트 맨 위에 적절한 태그 붙여줘."
- "제목 없는 메모들에 내용 기반으로 제목 지어줘."
- "거의 중복인 메모들 찾아서 하나로 합쳐줘."

**연결**
- "서로 관련 있는 노트끼리 `[[위키링크]]`로 이어줘."
- "이 주제에 대해 내가 적어둔 메모 전부 모아서 한눈에 보이게 정리 노트 만들어줘."

**발전**
- "20-Ideas의 이 아이디어를 실행 계획(할 일 목록)으로 구체화해줘."
- "이 흩어진 메모 3개를 매끄러운 한 편의 글로 합쳐줘."
- "이번 주 인박스 내용 요약해서 주간 회고 노트 만들어줘."

---

## 🏷 태그 & 링크 팁

- **태그:** 노트 아무 곳에 `#아이디어` `#할일` `#독서` 처럼. 나중에 검색이 쉬워져요.
- **링크:** `[[다른 노트 제목]]` 으로 노트끼리 연결. 옵시디언의 진짜 힘은 여기서 나옵니다.
- 프론트매터(노트 맨 위 `---` 블록)에 날짜/태그를 넣어두면 Claude가 정리하기 더 쉬워요. `Templates/` 폴더의 템플릿을 참고하세요.
