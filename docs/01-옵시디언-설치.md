# 1️⃣ 옵시디언 설치 (Mac · 아이폰 · 아이패드)

옵시디언은 **무료**이고, 메모를 그냥 마크다운(`.md`) 텍스트 파일로 저장합니다. 그래서 특정 회사에 묶이지 않고, Claude 같은 도구와도 자유롭게 연동돼요.

---

## 📥 설치하기

### Mac
1. https://obsidian.md 접속 → **Download** (Apple Silicon / Intel 맞는 것)
2. 다운로드한 `.dmg` 열고 Applications 폴더로 드래그
3. 실행

### 아이폰 / 아이패드
1. App Store에서 **"Obsidian"** 검색
2. 설치 (개발사: Dynalicious LLC / Obsidian)

> 💡 세 기기 모두 같은 앱입니다. 계정 가입 없이도 바로 쓸 수 있어요.

---

## 🗂 볼트(Vault) 만들기

**볼트 = 메모들이 담기는 하나의 폴더**입니다. 우리는 이 저장소 구조를 그대로 볼트로 쓸 거예요.

### 방법 A) 이 저장소를 볼트로 쓰기 (Claude 연동에 유리)
1. 이 저장소를 Mac에 clone (또는 다운로드)
2. 옵시디언 실행 → **"Open folder as vault"** → 이 폴더 선택
3. 끝! `00-Inbox`, `10-Notes` 같은 폴더가 보이면 성공

### 방법 B) 새 볼트를 iCloud에 만들기 (기기 동기화에 유리)
1. 옵시디언 실행 → **"Create new vault"**
2. 위치를 **iCloud Drive** 안으로 지정 (동기화 편의성 ↑ — [3번 문서](03-기기간-동기화.md) 참고)
3. 이 저장소의 폴더 구조(`00-Inbox` 등)를 그 볼트에 복사

> ⚖️ **어떤 걸 고르죠?**
> 애플 기기 3대 동기화가 최우선이면 **B (iCloud)**, Claude 연동/버전 백업이 최우선이면 **A**.
> 사실 둘을 합칠 수도 있어요 — [3번 문서](03-기기간-동기화.md)에서 "iCloud + Git 병행"으로 설명합니다.

---

## ✅ 설치 확인

옵시디언에서 아무 폴더나 우클릭 → **New note** → 글자 몇 개 입력.
아이폰에서도 같은 볼트가 열리면 이번 단계 완료입니다.
