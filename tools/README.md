# 🛠 자동 이전 도구

메모를 **명령어 한 줄로** 옵시디언 볼트에 옮기는 스크립트 모음입니다. 모두 **당신의 Mac(터미널)** 에서 실행하세요. (제가 클라우드에서 당신의 메모에 직접 접근할 수 없어, 대신 실행만 하면 되도록 완성해 두었습니다.)

---

## 1. 애플 메모 자동 이전 — `migrate.sh`

애플 "메모" 앱의 **모든 노트를 자동으로** 마크다운 변환해 `10-Notes/애플메모/`에 넣습니다. 폴더 구조·제목·생성일까지 보존해요.

```bash
# 볼트 폴더로 이동한 뒤
bash tools/migrate.sh
```

- 실행 중 macOS가 **"메모 앱 접근 허용"** 을 물으면 → **허용**
- 서식(굵게/목록/링크)까지 살리려면 미리:  `brew install pandoc`
  (없어도 macOS 내장 `textutil`로 텍스트는 깔끔하게 변환됩니다)

---

## 2. 삼성 메모·기타 파일 가져오기 — `import-files.sh`

삼성 메모나 다른 앱에서 **`.txt` / `.html` / `.md` 로 내보낸 파일들**이 담긴 폴더를 통째로 가져옵니다. → `10-Notes/가져온메모/`

```bash
bash tools/import-files.sh ~/Downloads/삼성메모내보내기
```

> 삼성 메모: 앱에서 **⋮ → 파일로 저장(TXT/HTML)** 으로 내보낸 폴더를 위 경로에 넣으세요.

---

## 실행 후

옵시디언에서 새로 생긴 폴더를 확인하고, 저(Claude)에게 정리를 맡기세요:

> "10-Notes/애플메모 안의 메모들 주제별로 분류하고, 제목·태그 정리해줘."

---

### ❓ 왜 제가 직접 못 옮기나요?
당신의 애플/삼성 메모는 **당신 기기의 iCloud/로컬**에 있고, 저는 격리된 클라우드 환경에서 동작하기 때문에 그 데이터에 접근할 수 없습니다. 그래서 **접근이 필요한 부분만 당신이 한 줄 실행**하고, 그 뒤 정리·가공은 전부 저에게 맡기는 구조가 가장 안전하고 빠릅니다.

만약 메모를 **Google Drive**로 내보낼 수 있다면, 그건 제가 이 세션에서 직접 접근해 변환·정리까지 해드릴 수 있어요. (원하시면 말씀 주세요.)
